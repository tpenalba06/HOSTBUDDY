| Décision                       | Architecte                                                    | Simplificateur                                                    | Développeur                                                                           | Contradicteur                                                                                             | Directeur produit                                                            |
| ------------------------------ | ------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| HTTP direct puis parseur DOM   | Même extraction pour accueil et gestionnaire                  | Réutilisation de parse5 et du client HTTP                         | Le classificateur existant reçoit le texte et les preuves structurées                 | Les accès refusés restent bloqués. La réponse doit contenir du HTML exploitable                           | Les pages de recette s’importent sans fournisseur externe                    |
| Détection et droits des photos | Les catégories suivent les médias et les rubriques existantes | Métadonnées et indices de galerie suffisent pour ce premier essai | Les variantes d’une image sont regroupées et le classement est recalculé côté serveur | Une photo candidate n’établit aucun droit. La copie garde les contrôles de source, de réseau et de tenant | Le gestionnaire confirme les droits. Le téléphone anonyme utilise Smart Fill |

Le moteur lit les métadonnées, le JSON-LD, les objets logement typés présents dans les scripts JSON et le texte du document. Il sélectionne les photos déclarées et les galeries identifiables, en utilisant les descriptions et légendes. Les types de données privés ou non typés demandent un adaptateur documenté. Les galeries rendues uniquement après exécution JavaScript et les doublons visuels portant des chemins différents restent hors de cette recette.

Les catégories correspondent d’abord à une rubrique existante. Les photos de chambres, cuisine, salon, extérieurs, salle de bain et équipements rejoignent La maison si la rubrique spécifique est absente. La piscine rejoint sa rubrique si elle existe. La couverture rejoint Bienvenue. Il n’y a pas de nouvelle structure de données persistante.

Sur la Preview isolée TEST, Airbnb et Booking passent directement par le client HTTP et le parseur HTML du moteur. La vérification robots.txt précède le chargement de l'annonce. En cas de redirection vers une autre URL, de défi anti-robot ou de refus HTTP, le moteur s'arrête. Les limites réseau et la vérification des droits média restent actives.

## Fiabilisation des annonces Airbnb

| Perspective       | Décision                                                                                                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Architecte        | La homepage et le gestionnaire partagent le client HTTP, le DOM et l’extracteur.                                                                                                            |
| Simplificateur    | Les faits visibles du logement proviennent de son en-tête et de la liste d’équipements. Les scripts de réservation et les appels supplémentaires sont hors parcours.                        |
| Développeur       | Les variantes redimensionnées d’une même photo sont regroupées. Le moteur privilégie la couverture confirmée par le catalogue et utilise les légendes ou le contexte pour classer le reste. |
| Contradicteur     | Un libellé du calendrier ne prouve aucun horaire. Une photo sans légende reste générique. Les références photo restent distinctes des droits de réutilisation.                              |
| Directeur produit | Le téléphone montre les faits disponibles et conserve Smart Fill tant qu’il ne dispose pas d’une photo fournie avec les droits nécessaires.                                                 |

Booking conserve l’arrêt sur une réponse de protection. Firecrawl est indépendant de l’import automatique. Pour un accès pérenne, [Demand API](https://developers.booking.com/demand/docs/getting-started/prerequisites) exige un compte Managed Affiliate Partner et des identifiants. [Connectivity](https://developers.booking.com/connectivity/docs/connections-api/connections-overview) demande une affiliation et l’autorisation du gestionnaire pour les données du logement concerné. Dans les deux cas, vérifier que les droits permettent un livret NONA avant toute copie.

## Export HTML du gestionnaire

| Perspective       | Décision                                                                                                                                                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Architecte        | La homepage et l’espace gestionnaire partagent la décision d’accès. L’export alimente le même analyseur HTML.                                                                                                                                        |
| Simplificateur    | Réutiliser le sélecteur de fichiers existant et la revue du brouillon.                                                                                                                                                                               |
| Développeur       | Conserver les métadonnées et références média du fichier. Produire un brouillon avec les champs extraits.                                                                                                                                            |
| Contradicteur     | Un onglet NONA ne lit pas le DOM d’un autre site. Une extension avec accès à l’onglet élargirait les permissions et ne conférerait pas les droits de collecte. Le fichier soumis est analysé sans exécution, requête média ni stockage du HTML brut. |
| Directeur produit | Distinguer une source non autorisée d’une requête refusée. L’export autorisé débloque la revue des données, avec ajout manuel des images, tandis que le test URL réel reste conditionné à l’accès source.                                            |
