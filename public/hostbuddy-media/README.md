# HostBuddy illustrative media

Original generated assets created for HostBuddy using the built-in image generation tool, 3 October 2026. These scenes are illustrative; they are never evidence of amenities, a destination or an actual property. Served as WebP at 960px, approximately 936 KB for the complete nine-image pack. PNG originals remain in the authoring workspace and are not shipped.

Prompt template: “Use case: photorealistic-natural. Asset: HostBuddy premium travel guide default [key] image. Single standalone landscape editorial photograph of [subject]. Mediterranean ivory, sage, sea blue, muted taupe palette, natural textures, refined soft daylight, uncluttered composition. No text, logos, UI or watermarks. This is an illustrative ambience, not an actual property.”

Subjects: Wi-Fi router on oak console; brass key at an entrance; suitcase at checkout; welcoming host offering tea; urban boutique hotel room; alpine chalet; canvas glamping tent; bright apartment; stone countryside guesthouse.

Existing demonstration images used for restaurant, breakfast and coast remain the previously supplied project assets. Hosts' real images take priority. No image is generated anew for each import.
