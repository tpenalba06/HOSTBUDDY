# Assets Nona officiels

Logo et portrait raster officiels issus de `NONA-charte-graphique-2026-10-17.zip`.
`official-da.png` est la référence A intacte, dont le personnage entier est recadré par CSS côté gestionnaire.
`mascotte-reference.png` est utilisé dans le guide et le chat via `src/lib/nona-assets.ts`.
Les fontes locales et leurs licences se trouvent dans `fonts/`.

L'animation finale de coucou et les masters vectoriels/transparents ne sont pas fournis.
Aucune mascotte ni animation de remplacement n'est générée. La réduction des animations reste respectée.
